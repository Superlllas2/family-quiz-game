# Sketchfab models: license log

Downloaded once through the Blender MCP add-on (it needs a Sketchfab account, so a script cannot fetch them again) and
committed as .glb files. tools/blender/build_props.py turns them into the studio's prop models. Only CC BY (CC
Attribution 4.0) models are used: never NC, ND or SA, so the game can be sold (D1, the rule in `docs/12_audio.md`).
CC BY needs the attribution text below wherever the game lists its credits.
