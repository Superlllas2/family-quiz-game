# Decision record 0020: the question bank test, sound effects and last call off

Date: Nov 6, 2026. Ilia asked for a start screen to choose between the current bank and a better one, used only for testing which questions play better (not for the finished game); a set of topics with about 10 refined questions each; several games of both and a later comparison by topic and by the same question; sound effects, among them a host voice he picks from offered options and the most important effects chosen by the AI (a ticking clock for the time left); and, if another player's answer shortens the timer, a fix so other players' choices never affect it. It did: that was last call (D74). The AI building the game never reopens one of these on its own; it asks first.
